# Vision statement draft versions

Earlier versions of `vision/vision-statement-claude.md`, kept because the project README
asks for "early draft versions of each product vision as well as a detailed log of the
prompts that were used to generate the visions."

Each revision overwrote the file in place during the working sessions, so these were
recovered afterwards from the editor's own session snapshots. Forty-five snapshot copies
existed, most differing only trivially; the eight below are the points where the document
actually changed in a meaningful way. Filenames carry the real file modification time,
which is the reliable chronology for this set.

| Version | Words | What changed |
| --- | --- | --- |
| v1 | 1795 | First attempt, from the session before the work was restarted. Used Moore's keyword template unprompted. |
| v2 | 1577 | Restarted from scratch. Dropped the keyword template in favour of descriptive prose. |
| v3 | 1963 | Scope answers folded in: guests browse only, one QR code, orders bound to table and server. |
| v4 | 2156 | Per-item status model with transition ownership split between kitchen and server. |
| v5 | 2552 | Check splitting, divided items, rounding rule, and the device decisions. |
| v6 | 3110 | Added the "why a restaurant would choose this" section, including the competitive comparison. |
| v7 | 3119 | Vision statement restructured onto Moore's keyword template. |
| v8 | 3223 | FOR clause reaimed at the buyer, WHO clause at the staff who feel the pain. |

The current version is `vision/vision-statement-claude.md`.

Worth noting for the model critique: v1 applied Moore's template without being asked, and
v2 abandoned it when the work restarted. The same model, on the same product, was
inconsistent about following the book's convention across two runs, and it took an
explicit instruction at v7 to get it back.
