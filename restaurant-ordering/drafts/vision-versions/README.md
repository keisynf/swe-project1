# Vision statement draft versions

Earlier versions of `vision/vision-statement-claude.md`, kept because the project README
asks for "early draft versions of each product vision as well as a detailed log of the
prompts that were used to generate the visions."

Each revision overwrote the file in place during the working sessions, so these were
recovered afterwards from the editor's own session snapshots. Forty-five snapshot copies
existed, most differing only trivially; the seven below are the points where the document
actually changed in a meaningful way. Filenames carry the real file modification time,
which is the reliable chronology for this set.

## A discarded first attempt, and why

An earlier run of this product was thrown away before v2 and is deliberately not kept here.
Its prompt had been drafted for me rather than written by me, and I wanted to judge what the
model produced from my own description of the product, in my own words, rather than from a
pre-written prompt. Restarting was the only way to get that, so the work from that run was
deleted and the product was described again from scratch. v2 is the first draft of the
surviving lineage.
