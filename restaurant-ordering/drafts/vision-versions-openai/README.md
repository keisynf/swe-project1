# Vision statement draft versions

Earlier versions of `vision/vision-statement-openai.md`, kept because the project README
asks for "early draft versions of each product vision as well as a detailed log of the
prompts that were used to generate the visions."

Each revision overwrote the file in place during the working session, so v1 and v2 were
recovered afterwards from the session record. The 1071-word state is in git history and is
not duplicated here. v3 is the full 1504-word version, saved when the vision was trimmed.
Filenames carry the time the file was written.
