# Vision statement draft versions

Earlier versions of `vision/vision-statement-openai.md`, kept because the project README
asks for "early draft versions of each product vision as well as a detailed log of the
prompts that were used to generate the visions."

Each revision overwrote the file in place during the working session, so these two were
recovered afterwards from the session record. Two later states are already in git history
and are not duplicated here. Filenames carry the time the file was written.
